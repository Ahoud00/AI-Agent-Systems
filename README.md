### نظام رفيق ومدار المدمج | REFEEQ Integrated Agentic Graph Hub 🔮

مشروع هندسي متكامل ومتقدم تم تطويره وفق معايير أكاديمية سدايا لبرنامج **"هندسة أنظمة الذكاء الاصطناعي التوكيلي المتقدمة"**. يدمج النظام بين واجهة تفاعلية ذكية للوكيل (Agentic UI) وبين خادم معالجة مستقل يعتمد على بنية العقد التتابعية (Multi-Node Graph Workflow). 

### 🏗️ البنية البرمجية للنظام (Architecture)

يتكون المشروع من ركيزتين أساسيتين تعملان بالتوازي: 

1. **الواجهة الأمامية (app.py):** مبنية بواسطة Streamlit وتتميز بتصميم فاخر باللونين الأسود والذهبي النيون، وتدعم التمركز المطلق في المتصفح دون الحاجة للسحب، مع شاشة تتبع حية لحركة العُقد الذكية.
2. **الخادم الخلفي للوكيل (server.py):** مبني بواسطة FastAPI ويعمل بشكل مستقل على المنفذ 8080 لاستقبال الأوامر، وتدقيق الأمان، وحقن منطق التفكير والمعالجة للنماذج اللغوية (LLM).

### 🛠️ متطلبات التشغيل والتجهيز (Setup)

تأكد من تفعيل البيئة الافتراضية وتنصيب المكتبات الأساسية قبل البدء: 

bash

# 1. تفعيل البيئة الافتراضية
source .venv/bin/activate

# 2. تنصيب الحزم البرمجية المطلوبة
pip install streamlit fastapi uvicorn requests python-dotenv

يُرجى استخدام الرمز البرمجي بحذر.

### 🔑 إعداد مفتاح الذكاء الاصطناعي الآمن

قم بإنشاء ملف باسم .env في المجلد الرئيسي للمشروع وضع بداخله مفتاحك الخاص: 

env

OPENROUTER_API_KEY="ضع_مفتاح_الأي_بي_آي_الخاص_بك_هنا"

يُرجى استخدام الرمز البرمجي بحذر.

### 🚀 طريقة تشغيل المشروع خطوة بخطوة

يتطلب تشغيل النظام فتح **نافتين منفصلتين في الترمينال (Terminal)** داخل VS Code ليعمل الطرفان معاً: 

### 📥 أولاً: تشغيل خادم الـ API الخلفي

في نافذة الترمينال الأولى، نفذ الأمر التالي: 

bash

python server.py

يُرجى استخدام الرمز البرمجي بحذر.

*سيعمل السيرفر ويظهر باللون الأخضر أنه نشط على الرابط: http://127.0.0.1:8080* 

### 💻 ثانياً: تشغيل واجهة المستخدم التفاعلية

افتح نافذة ترمينال ثانية جديدة (عبر علامة +)، ونفذ الأمر التالي: 

bash

streamlit run app.py

يُرجى استخدام الرمز البرمجي بحذر.

*سينطلق التطبيق تلقائياً ويفتح لك الواجهة الفاخرة في متصفح Safari المستقر.* 

### 🔄 خط سير العمليات للوكيل الذكي (Graph Nodes Flow)

عند إرسال أي أمر نصي عبر الواجهة، يمر الطلب حياً عبر ثلاث عُقد رئيسية: 

* **🛡️ العقدة الأولى (Security Guard):** لفحص وتدقيق أمان المدخلات وصلاحيات الأوامر.
* **🧠 العقدة الثانية (Reasoning Loop):** لتمرير الأمر إلى خادم المعالجة وحقن سياق الذكاء الاصطناعي.
* **⚙️ العقدة الثالثة (Execution Hub):** لتنفيذ القرار البرمجي المدمج وإرجاع النتيجة باللون الأخضر التفاعلي.
